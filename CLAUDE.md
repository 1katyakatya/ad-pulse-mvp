# Пульс рекламы

Учебный MVP для автоматизации рекламной отчётности из CSV. Контекст: PROJECT.md. План, полученный в Claude Code: PLAN.md. Проектный скилл: .claude/skills/ad-pulse/SKILL.md.

Запуск: npm start. Проверки: npm test. Node.js >=20, runtime-зависимостей нет.

Пользовательские файлы не сохраняются. Публичный пример содержит вымышленные данные. Итоговые коэффициенты считаются по суммам. Деление на ноль возвращает null. Новые интеграции и управление рекламой находятся за рамками MVP.
