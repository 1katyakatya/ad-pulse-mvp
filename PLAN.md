# Пульс рекламы — план разработки MVP

## Шаг 1. Данные и расчёты
- Модуль `public/metrics.js`: чистая функция `summarize(rows, targetCpl)`.
- Объединение строк по одинаковому `campaign`, суммирование показателей.
- Расчёт CTR, CPC, CR, CPL с защитой от деления на ноль (`null`).
- Статус кампании: `no-leads`, `expensive`, `ok`.
- Сортировка кампаний по расходу по убыванию.

## Шаг 2. Загрузка и проверка CSV
- Парсер CSV (UTF-8, русские и английские заголовки).
- Проверка обязательных колонок и неотрицательных чисел.
- Понятные сообщения об ошибках во входных данных.
- Встроенный демонстрационный пример с вымышленными кампаниями.

## Шаг 3. Интерфейс
- Загрузка файла и кнопка «пример».
- Поле настройки целевого CPL.
- Таблица кампаний, сводные показатели, фильтр проблемных кампаний.
- Адаптивная раскладка на русском языке.

## Шаг 4. Диаграмма и отчёт
- Простая диаграмма расходов по кампаниям (без внешних библиотек).
- Список наблюдений (no-leads, expensive).
- Скачивание текстового отчёта.

## Шаг 5. Проверка и документация
- Встроенные тесты для `summarize` на Node.js (без зависимостей).
- README с реальным скринкастом/скриншотом и инструкцией запуска.
- Проверка критериев приёмки из PROJECT.md.

## Порядок работы
1. metrics.js + тесты расчётов.
2. Парсинг и валидация CSV.
3. Верстка интерфейса и подключение расчётов.
4. Диаграмма, фильтр, отчёт.
5. README и финальная проверка критериев приёмки.
