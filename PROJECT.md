# Пульс рекламы — описание финального проекта

## 1. Название
Пульс рекламы — локальный анализатор эффективности рекламных кампаний.

## 2. Проблема
При подготовке рекламного отчёта приходится вручную сводить показатели из выгрузки, считать стоимость обращения и искать кампании с расходом без заявок. Эта повторяющаяся задача знакома по работе с рекламной аналитикой. MVP сокращает количество ручных вычислений и собирает черновик отчёта.

## 3. Пользователь
Маркетолог, специалист по контекстной рекламе или предприниматель, который проверяет кампании по таблице показателей.

## 4. Основная функция
На входе CSV в UTF-8 с колонками campaign, impressions, clicks, cost, leads. Можно использовать русские заголовки Кампания, Показы, Клики, Расход, Заявки. Приложение проверяет данные, объединяет строки одинаковых кампаний, рассчитывает CTR, CPC, CR и CPL, сравнивает CPL с заданной целью и выделяет расход без заявок. Анализ выполняется в браузере по прозрачным правилам.

## 5. Формат результата
Интерактивная сводка, таблица кампаний, список наблюдений и скачиваемый текстовый отчёт. На демонстрации используются только вымышленные кампании.

## 6. Минимальный функционал
- Загрузка CSV и встроенного примера.
- Проверка обязательных колонок и неотрицательных чисел.
- Сводные показатели и объединение одинаковых кампаний.
- Настройка целевой стоимости заявки и фильтр проблемных кампаний.
- Диаграмма расходов и выгрузка отчёта.
- Адаптивный интерфейс на русском языке.

Критерий приёмки: пример открывается локально; итоговые расход и заявки совпадают с исходными данными; CSV с ошибкой объясняет проблему; фильтр работает; отчёт скачивается; README показывает реальный экран; скилл находится в репозитории.

За рамками MVP: интеграция с API, авторизация, хранение истории, автоматическое управление рекламой. В будущем: сравнение периодов и дополнительные форматы выгрузок.

## 7. Технологии
JavaScript ES modules, HTML, CSS; Node.js 20+ для локального сервера и встроенных тестов. Внешние библиотеки и API-ключи не нужны. CSV читается в браузере и не отправляется на сервер. Данные живут только до перезагрузки страницы.

## Ограничения интерпретации
Сигналы — повод проверить кампанию, а не команда менять бюджет. Для оценки окупаемости нужны выручка, качество заявок, атрибуция и более длинный период. Нулевая заявка означает неопределённый CPL, а не нулевую цену.
